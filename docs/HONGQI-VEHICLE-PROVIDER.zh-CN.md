# 红旗3212只读车辆数据源

168新增 `HongqiVehicleData`，由CarPlay连接会话或显式诊断弹窗持有 `acquire(context)` 返回的Closeable。最后一个持有者关闭时解绑并清空实时状态。`snapshot()`及`diagnosticReport()`只读取内存，不在调用线程执行车辆Binder操作。它不更换既有车速、驻车、日夜或音频来源，也不向手机声明新的Ultra功能。

当前仅允许固件display ID为3212、Qisi包versionCode3167、versionName20240905-114725的组合。每次服务重新连接均复核该组合，失败后停止当前持有期的读取及重试。根与模块descriptor仍须逐一匹配；其他组合返回UNSUPPORTED，等待相应固件合约审核。模块缺失会单独重试，其他模块继续读取。所有事务均来自已核对的本机3212 Stub常量及接口/Proxy签名。

每批16项读取在单独串行工作线程执行，完成后等待2秒再采样；不并发积压批次。同步OEM Binder调用无法由Java强制取消，超过6秒的读数会在访问时失效；共享单工作线程防止重复开关页面产生多个阻塞线程。服务断开、关闭或换代后，迟到批次不能重新发布。

读数含来源、单调时钟采样时间、原值及失败状态。已知无效值不会变成0；被拒绝的有限原码仅保留在诊断的rejected字段。语义审查依据与范围：

- 车速0..32765保留RAW，32766/32767无效。单位未实车标定，不作为km/h或m/s发布。
- 挡位仅0..8和14进入有效RAW，其他有限码保留rejected原码；主驾门0/1不赋予开/关标签。不会把它们套入AAOS枚举。
- 续航不接受负值、65533/65535；不重复缩放。552现场样本尚未与原厂表逐项标定。
- 左右设温按getter已有的摄氏数值保留，参考范围15..35、0.5步进；不另行缩放，不推断LO/HI。
- 环境温度-40..86.5°C允许负值。NaN/Infinity与超域值均未知。
- 风量参考0..7，0合法；空调电源保留0/1/2原码。
- 座椅回读参考0..3，4保留rejected原码而不赋档位。能力仅接受boolean编码0/1，其他码为未知。

部分范围来自3222服务/原厂UI静态资料，不能当作3212全部实车标定。3212现场已确认两轮各16项可读，以及主驾设温26→25、通风0→1与原厂操作一致；当时使用独立诊断UID。168自身UID的读取、断连恢复和睡眠场景仍需安装后验收。

应用入口位于诊断页“保存与排查”中的“车辆状态（只读）”。关闭弹窗或宿主停止/销毁会释放该持有者；连接会话若仍活跃则保留其独立持有者。保存或手动上传诊断包含该内存数据源的当前状态，未采样或停止时如实标记未知。

本版没有车辆setter、主题更新、CAF写入或Ultra资源加载。下一步需分别完成产品UID实车读取验收、明确项目的车辆命令/新反馈闭环，以及真实UI Sync/车型资源、原厂告警仲裁与本地renderer；现有全幅地图输出是显示通道证据。
