# Autunn Play 0.2.58-AUTUNN1（132）

产品名称、客户端各语言文案、系统入口、设备展示、图标、官网、激活与授权后台统一为 Autunn Play。使用独立绘制的几何 A 图形，替换原 CarPlay 返回入口的红旗图形。

旧默认返回标签精确迁移至新名称；旧默认图标如被保存为自定义图标，则使用新默认图标并保留原文件供回滚。其他自定义标签和图像不覆盖。

新建可控热点使用新品牌名称，保留同一设备的稳定标识后缀，并继续识别该设备的旧命名空间。已有 Wi-Fi Direct 系统组和凭据不为改名主动清除；系统缓存的旧名称可能在后续自然重建后更新，手机缓存刷新仍需实机确认。

包名、正式发布签名、设备身份、手机配对、授权密钥、授权有效期及更新协议继续沿用。新版服务端新生成兑换码使用 AUTUNN- 前缀，不改写已有卡密记录；新旧卡密均纳入日志脱敏。

本次不修改连接状态机和导航功能。编译、测试和实车验收结果见本次交付记录；更名本身不构成商标注册或法律结论。
