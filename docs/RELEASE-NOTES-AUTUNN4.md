# Autunn Play 0.2.61-AUTUNN4（135）

本次针对 134 版实车日志中导航播报断音、音乐缓冲耗尽及音轨结束时清空尾音的问题修改客户端。

- 导航起播预缓冲从 160 ms 调整为 240 ms，目标缓冲容量从 280 ms 调整为 400 ms，以覆盖日志中约 188 ms 的到包间断。
- 导航与音乐发生缓冲耗尽后，在处理下一批压缩音频前检查硬件可播余量，暂停并保留已有 PCM，积累到起播阈值再恢复。输入队列已有待解码包时，也能进入恢复。
- 单段导航音轨结束后，由音频工作线程继续处理已接收的包、解码器 EOS 尾帧和已写入的声音。短于起播阈值的提示立即开始播放尾音；完成过程最多等待 1 秒，不在会话控制锁内等待。
- 完整会话停止、断开、同音轨替换、来电及 Siri 抢占可立即取消待播尾音；电话、Siri 和音乐音轨结束不使用导航尾音等待。
- 新增重缓冲和尾音完成／取消／超时诊断。强制停止后不再把播放头清零误算成巨大的剩余队列或播放进度回绕。

本次没有修改路口大图、车道提示、启停判断、无线建组或服务端。

缓冲和尾音处理不能恢复传输中真正丢失的音频内容。新版本仍需在实车上验证导航完整性及音乐连续性，并结合新增记录判断是否还有输入序号缺口。
