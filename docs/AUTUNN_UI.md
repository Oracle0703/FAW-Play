# Autunn Play 双主题界面

原生 Android View 实现位于 `common/.../AutunnSettingsPage.java`。实体圆角卡片、胶囊按钮和线性图标适配 HS5 的 1920×720 / 160 dpi 横屏；不会改变系统密度或 CarPlay 视频尺寸。

浅色主色为 `#E72D48`，背景为 `#F1DDDF`；深色主色为 `#1DDFFF`，背景为 `#1A1A1D`。品牌标志采用同形双色图形，主按钮文字根据主题选择白色或炭黑色。

外观默认跟随车机。顶部外观按钮按“跟随车机 → 浅色 → 深色 → 跟随车机”循环并保存选择。`AutunnUiTheme` 的独立 `faw_ui` 偏好不会修改 CarPlay 昼夜模式、帧率、HUD 或连接偏好。自动模式优先采用现有 `HongqiNightModeSource` 的真实车机昼夜状态，其次使用 Android 的 `uiMode`。信号未知时保留上次自动主题，首次未知时使用深色。

`AutunnUiAppearanceWatch` 随 Activity 的 onStart/onStop 注册、解绑；系统外观回调缺失时每两秒检查一次。配色变化只重绘页面，不重新连接或断开会话。准备连接页重绘保留引擎的状态 TextView、重试与 Wi-Fi 恢复按钮实例及监听器，并保留隐藏状态，防止遮挡正在显示的 CarPlay。

首页与七类设置保留真实设备选择、连接、帧率、导航输出、权限、诊断和语言行为。设置左栏依次为“连接设置、画面显示、导航与 HUD（不支持时为定位）、权限与帮助、诊断、授权、关于”。三指左右滑动导航说明和固定自动连接规则沿用原逻辑。

“设置 → 授权”通过 `AutunnAuthorizationPanel` 显示真实 `ProductLicense` 状态和离线授权到期时间。UI35 将左侧授权状态与右侧两步扫码流程分成两个面板。购买码和设备激活码使用同尺寸圆角区域，标题、二维码和说明上下对齐，以步骤编号区分用途。购买码始终指向提供方的公开购买链接；已有授权码可跳过购买。

未生成设备二维码时显示跟随主题的扫描框图标和点击提示，可点击占位区或“生成激活二维码”按钮发起原有激活流程。真实二维码仍保持黑白和留白；手机扫码核对设备后输入兑换码，等待时“取消本次扫码”替换生成按钮。已授权时右侧改为 HUD、仪表地图和方向盘键控的功能说明，左侧保留真实授权状态、离线票据到期时间及“联网验证”按钮。开发版本明确显示未启用授权检查，服务配置缺失时禁用网络操作。授权页没有授权开关，也不改变原有 CarPlay 启动门禁。

主题重绘复用当前二维码和扫码流程；离开授权页或销毁 Activity 时停止等待并尽力取消服务端会话。手机已确认的有效授权仍保留。二维码维持黑白和留白，不随主题染色。

更新页交付版本为 `0.2.21-FAW-UI34 / versionCode 95`，使用固定源码快照构建。相关回归：`AutunnSettingsPageTest`、`PreparationLayoutTest`、`AutunnUiThemeTest`、`AutunnUiAppearanceWatchTest`、`AutunnUiIntegrationTest`、`AutunnAuthorizationPanelTest`、`AppUpdateActivityTest`。测试覆盖双主题布局和文字完整显示、设置保持、准备页实例与隐藏状态，以及真实授权状态映射、二维码内容、取消和主题重绑定；本轮检查结果以交付记录为准。

授权页面优化交付版本为 `0.2.27-FAW-UI35 / versionCode 101`，包含 UPD3 的已验证厂商安装入口和更新成功后自动打开主界面机制。界面预览通过只读 Android 模拟器和不访问服务器的测试后端生成，覆盖深浅主题、等待扫码和已授权状态；正式 APK 使用真实授权后端。

“关于 → 检查更新”使用同一品牌栏、配色和实体卡片的横屏页面，不使用上下滚动。版本、下载/安装状态及操作一屏显示；长更新说明根据实际文字区域分页，用上一页/下一页完整阅读。系统要求安装确认时，原系统安装按钮位置显示“继续系统确认”。主题和车机昼夜切换保留下载进度、新版本信息及更新说明页码，不重启更新任务。
