## 校验和复现

```sh
# 在交付归档目录校验三个压缩包。
(cd 交付归档 && shasum -a 256 -c SHA256SUMS.txt)

# 在任意解压包根目录校验全部交付文件。
python3 verify_source.py
```

Windows 可用 Python 执行包内校验脚本；Gradle 使用 `gradlew.bat`。macOS／Linux 解压后若权限丢失，执行 `chmod +x gradlew`。`manifest.json` 校验交付内容，`SOURCE_PROVENANCE.json` 记录工作树原始哈希及文档可移植性调整。源码不含 Git 历史；基础提交号不能代替当前快照的文件哈希。
