# 服务端架构与维护入口

服务端是独立 Spring Boot 3.5.6／Java 工程，使用 Spring Security JWT 验证、JdbcTemplate、PostgreSQL 和 Flyway。管理账号由 Keycloak 提供，普通扫码用户不要求邮箱和账号。授权签名采用服务端密钥，设备通过 Android Keystore 的独立密钥证明自身身份。

源码基准目录为 `server/authorization-server/src/main/`。

| 入口／模块 | 职责 |
|---|---|
| `LicenseController`、`LicenseService`、`LicenseTokens` | 挑战、账号兼容绑定、续期、授权签名与设备校验 |
| `ActivationController`、`ActivationService` | 设备签名申请二维码、手机核对／兑换、轮询、领取与取消 |
| `Administration` | 单码／批量码、授权和设备管理、替换设备、重置累计次数、总数和审计 |
| `AdminLogin`、`SecurityConfiguration` | 管理员登录桥接、issuer／audience／角色验证与路由权限 |
| `UpdateAdministration`、`UpdatePublisher`、`ApkInspection` | 上传 APK，解析并核对包名、版本和签名 |
| `UpdateController`、`UpdateService` | 签名更新清单、受限 artifact 下载 |
| `DiagnosticController`、`DiagnosticService` | 经设备证明的诊断上传及管理员读取 |
| `resources/db/migration/` | V1–V7 数据库结构及历史数据迁移 |
| `resources/static/admin/`、`static/activate/` | 管理页和手机激活页 |
| `server/site/` | 同源站点资源，由 Gradle 打入服务 JAR |

挑战是短时、一次性输入；设备签名绑定包名、设备公钥及具体操作。手机批准后由车机证明身份并领取授权。票据验签和本地功能判断发生在客户端；服务端返回的未签名时间本身不能解锁权限。离线期请求格式兼容 1–90 天，新签与续签硬上限 30 天，同时受服务端配置及购买截止时间限制。更新检查、下载及安装前授权复用实时购买资格和设备绑定校验，不重复兑换或登记设备。

授权设备上限表示未撤销绑定数，不代表实时并发在线；累计激活按首次登记的设备公钥计数。设备替换、撤销、恢复、删除和重置次数有各自审计语义，应复用现有事务入口，不直接手动改表模拟。

新增接口时同时维护控制器校验、权限路由、服务事务、数据库迁移、Java 集成测试及相关网页／CLI 测试。新增受支持包名需维护部署环境和对应签名配置，客户端更新渠道也要单独发布。完整字段和操作以 `server/docs/API.md`、`server/authorization-server/README.md` 和当前源代码为准。
